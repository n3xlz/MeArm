## 舵机引脚分配

meArm 官方命名（`arm.begin(basePin, shoulderPin, elbowPin, gripperPin)`）与本地变量名的对应关系：

| 代码变量 | 中文 | 英文（官方） | 引脚 | 角度范围 | 作用 |
| --- | --- | --- | --- | --- | --- |
| `base` | 底座 | base | D11 | 0 ~ 180 | 绕竖直轴水平旋转整个手臂 |
| `rArm` | **后臂** | **shoulder** | D10 | 20 ~ 110 | 俯仰：驱动靠近底座的那一段 |
| `fArm` | **前臂** | **elbow** | D9 | 40 ~ 130 | 俯仰：驱动靠近爪子的那一段 |
| `claw` | 爪子 | gripper | D5 | 25 ~ 100 | 开合 |

> 记忆口诀：**肩膀管后臂，肘管前臂**。
> 几何依据：shoulder 舵机装在底座立柱顶端，舵盘驱动第一段（离底座近）= 后臂；
> elbow 舵机装在后臂末端，舵盘驱动第二段（离爪子近）= 前臂。

### 命名冲突提醒

- **任务一**里的 `x` / `y` / `z` 是**舵机编号**，参数是**角度**（0 ~ 180）
- **任务四 / 五**里的 `x` / `y` / `z` 是**笛卡尔坐标**，单位是**毫米**

两组字母同名、含义完全不同。写任务五代码时建议把坐标那组命名为 `px` / `py` / `pz`，避免混用。

## 串口指令表

| 指令  | 格式      | 含义          |
| --- | ------- | ----------- |
| `b` | `b<角度>` | 底座转到指定角度    |
| `r` | `r<角度>` | 后臂转到指定角度    |
| `f` | `f<角度>` | 前臂转到指定角度    |
| `c` | `c<角度>` | 爪子转到指定角度    |
| `x` | `x<a>,y<b>,z<c>` | 同步控制三个舵机（底座 / 后臂 / 前臂）|
| `O` | `O`     | 爪子张开（到 `clawMax`） |
| `S` | `S`     | 爪子合上（到 `clawMin`） |
| `H` | `H`     | 提速：`DSD - 3`（下限 9） |
| `L` | `L`     | 减速：`DSD + 3`（上限 45） |
| `?` | `?`     | 打印当前四个舵机的角度 |
| `I` | `I`     | 恢复到初始位置     |
| `N` | `N`     | 任务三 按键1：循环夹取（A → B → C → A） |
| `R` | `R`     | 任务三 按键2：录制（按一下开始 / 再按一下结束） |
| `P` | `P`     | 任务三 按键3：播放上一次录制 |
| `Z` | `Z`     | 任务三 按键4：回中（与 `I` 等效） |
| `K` | `K`     | 调试：摇杆按键引脚探测模式 开 / 关 |

> **大小写敏感**：`O` / `S` / `H` / `L` / `I` 是大写字母，`b` / `r` / `f` / `c` / `x` 是小写。
> 发错大小写会返回 `Unknown Command.`
>
> `DSD` 是「每走 1 度之间的延迟毫秒数」（默认 15）。**值越小，动作越快。**

## 任务三 · 4 个按键怎么来（复用摇杆按键 + 单击 / 双击）

**不需要额外的按键板。** 两个摇杆本身各带一个按压开关（把摇杆帽垂直往下按就触发），用「单击 / 双击」组合出 4 种手势：

| 任务要求 | 触发手势 | 机械臂动作 | 分值 |
| --- | --- | --- | --- |
| 按键1 | **左摇杆 单击** | 循环夹取：按一次做一个物体，A → B → C → A 依次循环 | 10% |
| 按键2 | **右摇杆 单击** | 录制：第一次按下开始（人工用摇杆操控），第二次按下结束并保存 | — |
| 按键3 | **左摇杆 双击** | 播放：完整复现上一次录制的动作 | 10% |
| 按键4 | **右摇杆 双击** | 回中：四轴回到 90° | 5% |

串口发 `N` / `R` / `P` / `Z` 触发的是**完全相同的四个功能**，用于没有手柄时的调试。
（若后续仍要接外接按键板，按这张表发字符即可，机械臂侧不用改代码。）

### 为什么单击有约 0.4 秒延迟

识别手势靠的就是「等一等」：

- 手松开后要等一个 **350 ms 的双击窗口**（`BTN_DOUBLE_MS`）。
  窗口内没有第二次按下 → 判定单击；有 → 判定双击。
- 因此**单击从按下到响应约 0.4 秒**。这不是卡顿，是区分单双击的必然代价。
- **双击请按快一点**：两次点击的间隔必须小于 0.35 秒，否则会被识别成两次单击
  （结果是循环夹取被触发两次）。

### 引脚探测（`K` 命令）

发 `K` 进入探测模式 → 按一下摇杆按键 → 串口打印该按键所在的引脚号 → 再发 `K` 退出。

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 消抖时间 | 25 ms | 电平稳定这么久才算一次有效动作，见 `BTN_DEBOUNCE_MS` |
| 双击窗口 | 350 ms | 见 `BTN_DOUBLE_MS` |
| 探测候选引脚 | D2 D3 D4 D6 D7 D8 A4 A5 | 已排除舵机 D5/9/10/11、摇杆四轴 A0~A3、串口 D0/D1 |

探测模式下**手势识别被暂停**，按摇杆不会触发机械臂动作，可以放心按。

### 录制能力

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 采样周期 | 100 ms（10 帧/秒） | 见 `FRAME_MS` |
| 最大帧数 | 200 帧 = **20 秒** | 见 `MAX_FRAMES`，满足题目「>10 秒」要求 |
| 占用 RAM | 800 字节 | 每帧 4 个 `byte`（四轴各 1 个） |

- 录制中若录满 200 帧会**自动停止**并打印 `+REC FULL, auto stop`
- 播放时两帧之间做 5 次插值，动作是连续的，不会一格一格跳

### 已知限制

`循环夹取` / `播放` / `回中` 三个动作内部是 `delay` 死循环，**执行期间摇杆、串口、按键全部失效**，必须等它跑完。采样函数 `recordTick()` 和手势识别 `scanButtons()` 则已经是非阻塞写法（只查 `millis()`，不 `delay`），所以录制期间摇杆仍可实时操控。
