## 舵机引脚分配

meArm 官方命名（`arm.begin(basePin, shoulderPin, elbowPin, gripperPin)`）与本地变量名的对应关系：

| 代码变量   | 中文     | 英文（官方）       | 引脚  | 角度范围     | 作用            |
| ------ | ------ | ------------ | --- | -------- | ------------- |
| `base` | 底座     | base         | D11 | 0 ~ 180  | 绕竖直轴水平旋转整个手臂  |
| `rArm` | **后臂** | **shoulder** | D10 | 20 ~ 110 | 俯仰：驱动靠近底座的那一段 |
| `fArm` | **前臂** | **elbow**    | D9  | 40 ~ 130 | 俯仰：驱动靠近爪子的那一段 |
| `claw` | 爪子     | gripper      | D5  | 25 ~ 110 | 开合            |

> 记忆口诀：**肩膀管后臂，肘管前臂**。  
> 几何依据：shoulder 舵机装在底座立柱顶端，舵盘驱动第一段（离底座近）= 后臂；  
> elbow 舵机装在后臂末端，舵盘驱动第二段（离爪子近）= 前臂。

### 命名冲突提醒

- **任务一**里的 `x` / `y` / `z` 是**舵机编号**，参数是**角度**（0 ~ 180）
- **任务四 / 五**里的 `x` / `y` / `z` 是**笛卡尔坐标**，单位是**毫米**

两组字母同名、含义完全不同。写任务五代码时建议把坐标那组命名为 `px` / `py` / `pz`，避免混用。

## 串口指令表

| 指令  | 格式               | 含义                          |
| --- | ---------------- | --------------------------- |
| `b` | `b<角度>`          | 底座转到指定角度                    |
| `r` | `r<角度>`          | 后臂转到指定角度                    |
| `f` | `f<角度>`          | 前臂转到指定角度                    |
| `c` | `c<角度>`          | 爪子转到指定角度                    |
| `x` | `x<a>,y<b>,z<c>` | **同步**控制三个舵机（x=底座 / y=后臂 / z=前臂），执行后回读实际角度 |
| `O` | `O`              | 爪子张开（到 `clawMax`）           |
| `S` | `S`              | 爪子合上（到 `clawMin`）           |
| `H` | `H`              | 提速：`DSD - 5`（下限 5），回显 `DSD=..` |
| `L` | `L`              | 减速：`DSD + 5`（上限 60），回显 `DSD=..` |
| `?` | `?`              | 打印当前四个舵机的角度                 |
| `I` | `I`              | 恢复到初始位置                     |
| `N` | `N`              | 任务三 按键1：循环夹取（A → B → C → A） |
| `R` | `R`              | 任务三 按键2：录制（按一下开始 / 再按一下结束）  |
| `P` | `P`              | 任务三 按键3：播放上一次录制             |
| `Z` | `Z`              | 任务三 按键4：回中（与 `I` 等效）        |

> **大小写敏感**：`O` / `S` / `H` / `L` / `I` 是大写字母，`b` / `r` / `f` / `c` 是小写。  
> 发错大小写会返回 `Unknown Command.`（坐标指令 `x` / `X` 两种都收。）
>
> `DSD` 是「每走 1 度之间的延迟毫秒数」（默认 15）。**值越小，动作越快。**
> 可调范围 `5 ~ 60`（`DSD_MIN` / `DSD_MAX`），即最快与最慢相差 **12 倍**。

## 任务一 · 多舵机协同控制

**x / y / z 与舵机的对应关系（自行定义）**

| 编号  | 舵机     | 中文  | 角度范围     |
| --- | ------ | --- | -------- |
| `x` | `base` | 底座  | 0 ~ 180  |
| `y` | `rArm` | 后臂  | 20 ~ 110 |
| `z` | `fArm` | 前臂  | 40 ~ 130 |

一条指令同时驱动三个轴 —— 底层走 `moveAll` 的**比例插值**：先算三个轴里最长的行程 = 总步数，
第 `s` 步时每个轴都走到「自己行程的 s / 总步数」处，因此三轴**同时出发、同时到达**。
夹爪不参与，保持不动。

> 与 `b` / `r` / `f` 的区别：那三个是**单轴**指令，而且各自走完才轮到下一个（一顿一顿）。
> `x` 是**三轴同步**，一气呵成。

### 演示数据：两组大幅度端点

| 组 | 指令             | 姿态                       |
| -- | -------------- | ------------------------ |
| A  | `x30,y110,z50`  | 底座靠左、后臂抬到顶、前臂压低          |
| B  | `x150,y80,z120` | 底座靠右、后臂放平、前臂抬高           |

A → B 的行程：底座 **120°**、后臂 30°、前臂 70° —— 总步数由最长的底座决定，**120 步**。

| DSD | 单程耗时（估算） |
| --- | -------- |
| 5（最快） | ≈ 0.6 s  |
| 15（默认） | ≈ 1.8 s  |
| 60（最慢） | ≈ 7.2 s  |

最慢比最快慢 **12 倍**，肉眼对比非常明显。

> 这两个姿态的取值全部落在任务二**已实测过**的安全范围内
> （base 18~174 / rArm 80~110 / fArm 40~120），不会撞台面、不触发限位。

### 现场演示流程（约 40 秒）

| 步骤 | 发什么            | 看到什么                    |
| -- | -------------- | ----------------------- |
| 1  | `I`            | 四轴回中，统一起点               |
| 2  | `L` × 9        | 串口打印 `DSD=` 从 20 一路涨到 60 |
| 3  | `x30,y110,z50`  | 慢速走到 A 端（约 7 秒）          |
| 4  | `x150,y80,z120` | 慢速走到 B 端（约 7 秒）—— 顺便展示三轴同步 |
| 5  | `H` × 11       | `DSD=` 从 55 一路降到 5       |
| 6  | `x30,y110,z50`  | 快速回到 A 端（约 0.6 秒）        |
| 7  | `x150,y80,z120` | 快速回到 B 端                 |

**第 3~4 步和第 6~7 步发的是完全相同的两条指令，只有速度不同。**
重复同一动作、中间调一次速，差异一眼可见 —— 这是最有说服力的演示方式。

> `DSD` 默认 15：`L` 按 9 次到顶（60），`H` 按 11 次到底（5）。
> 每次都会在串口打印当前 `DSD=`，可以边按边把数字报出来。

## 任务三 · 4 个按键怎么来（复用摇杆按键 + 单击 / 双击）

**不需要额外的按键板。** 两个摇杆本身各带一个按压开关（把摇杆帽垂直往下按就触发），用「单击 / 双击」组合出 4 种手势：

| 任务要求 | 触发手势       | 机械臂动作                            | 分值  |
| ---- | ---------- | -------------------------------- | --- |
| 按键1  | **左摇杆 单击** | 循环夹取：按一次做一个物体，A → B → C → A 依次循环 | 10% |
| 按键2  | **右摇杆 单击** | 录制：第一次按下开始（人工用摇杆操控），第二次按下结束并保存   | —   |
| 按键3  | **左摇杆 双击** | 播放：完整复现上一次录制的动作                  | 10% |
| 按键4  | **右摇杆 双击** | 回中：四轴回到 90°                      | 5%  |

串口发 `N` / `R` / `P` / `Z` 触发的是**完全相同的四个功能**，用于没有手柄时的调试。  
（若后续仍要接外接按键板，按这张表发字符即可，机械臂侧不用改代码。）

### 为什么单击有约 0.4 秒延迟

识别手势靠的就是「等一等」：

- 手松开后要等一个 **350 ms 的双击窗口**（`BTN_DOUBLE_MS`）。  
  窗口内没有第二次按下 → 判定单击；有 → 判定双击。
- 因此**单击从按下到响应约 0.4 秒**。这不是卡顿，是区分单双击的必然代价。
- **双击请按快一点**：两次点击的间隔必须小于 0.35 秒，否则会被识别成两次单击  
  （结果是循环夹取被触发两次）。

### 按键引脚与手势参数

| 手势来源  | 引脚 |
| ----- | -- |
| 左摇杆按键 | D2 |
| 右摇杆按键 | D4 |

（2026-10-12 实测确认）

| 参数   | 值      | 说明                                  |
| ---- | ------ | ----------------------------------- |
| 消抖时间 | 25 ms  | 电平稳定这么久才算一次有效动作，见 `BTN_DEBOUNCE_MS` |
| 双击窗口 | 350 ms | 见 `BTN_DOUBLE_MS`                   |

### 录制能力

| 参数     | 值                | 说明                           |
| ------ | ---------------- | ---------------------------- |
| 采样周期   | 100 ms（10 帧/秒）   | 见 `FRAME_MS`                 |
| 最大帧数   | 200 帧 = **20 秒** | 见 `MAX_FRAMES`，满足题目「>10 秒」要求 |
| 占用 RAM | 800 字节           | 每帧 4 个 `byte`（四轴各 1 个）       |

- 录制中若录满 200 帧会**自动停止**并打印 `+REC FULL, auto stop`
- 播放时两帧之间做 5 次插值，动作是连续的，不会一格一格跳

### 已知限制

`循环夹取` / `播放` / `回中` 三个动作内部是 `delay` 死循环，**执行期间摇杆、串口、按键全部失效**，必须等它跑完。采样函数 `recordTick()` 和手势识别 `scanButtons()` 则已经是非阻塞写法（只查 `millis()`，不 `delay`），所以录制期间摇杆仍可实时操控。

## 任务四 · 运动学模型速览（代码里要用到的部分）

完整推导见 `Task4/任务四-运动学推导.docx`（约 9 页，32 个编号公式）。这里只留实现时要查的结论。

**构型简化**：夹爪开合不改变被夹物体的中心位置，故位置机构只有 3 个自由度  
（`base` / `rArm` / `fArm`），可等效为「底座回转 + 竖直平面内 2R 串联平面臂」。

**连杆参数**（标称值，实测见文档附录 A）：

| 参数   | 含义                 | 值      |
| ---- | ------------------ | ------ |
| `D`  | 底座回转轴 → 肩关节轴 的水平偏置 | 15 mm  |
| `H`  | 安装底面 → 肩关节轴 的高度    | 64 mm  |
| `L1` | 大臂（肩 → 肘）          | 80 mm  |
| `L2` | 小臂（肘 → 腕）          | 80 mm  |
| `L3` | 腕 → 夹持中心           | 53 mm  |
| `Lf` | 等效小臂长度 `L2 + L3`   | 133 mm |

**正解**（关节角 → 末端坐标，单位 mm）：

```
x = cosθ1 · (D + L1·cosθ2 + Lf·cos(θ2+θ3))
y = sinθ1 · (D + L1·cosθ2 + Lf·cos(θ2+θ3))
z = H + L1·sinθ2 + Lf·sin(θ2+θ3)
```

**逆解**（末端坐标 → 关节角）：

```
θ1 = atan2(y, x)
r  = √(x²+y²) − D ,  z' = z − H
θ3 = ± arccos[ (r²+z'² − L1² − Lf²) / (2·L1·Lf) ]
θ2 = atan2(z', r) − atan2(Lf·sinθ3, L1 + Lf·cosθ3)
```

- 两组解来自 `θ3` 的 ± 号（肘上 / 肘下构型）。任务五按**固定构型**准则取肘上解，避免绘制中途肘部翻转。
- 可达条件：`|L1 − Lf| ≤ ρ ≤ L1 + Lf`（即 53 ~ 213 mm）。
- 关节角 → 舵机角度：`a_i = a_i⁰ + σ_i·θ_i`（`σ_i = ±1` 由安装方向决定），再用串口指令表里的角度范围做限位校验。
